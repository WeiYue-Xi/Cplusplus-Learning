# 内存管理入门示例

代码按知识点拆分，每个 `test_...` 函数只演示一个知识点。`main.cpp` 只负责依次调用这些函数。

## 文件结构

```text
memory_management/
├── main.cpp                     程序入口，调用示例
├── CMakeLists.txt               告诉编译器需要编译哪些文件
└── examples/
    ├── examples.h              五个示例函数的声明
    ├── Student.h               Student 类的声明
    ├── Student.cpp             构造函数、析构函数的实现
    ├── 01_new_delete.cpp       单个整数
    ├── 02_array.cpp            动态数组
    ├── 03_student.cpp          类对象
    ├── 04_malloc_free.cpp      原始空间的申请与释放
    └── 05_placement_new.cpp    定位 new
```

`.h` 文件声明有哪些函数、类，`.cpp` 文件写具体怎么做。例如，`main.cpp` 包含 `examples.h` 后就知道可以调用 `test_int()`；该函数的实现写在 `01_new_delete.cpp` 中，构建时由 CMake 把这些源文件一起编译、链接成一个程序。

## 阅读顺序

建议按顺序阅读：

1. `test_int`：用 `new` 创建一个整数，再用 `delete` 释放。
2. `test_array`：用 `new[]` 创建数组，再用 `delete[]` 释放。
3. `test_student`：观察 `new` 和 `delete` 如何调用构造函数与析构函数。
4. `test_malloc`：观察 `malloc/free` 只申请、释放空间，不调用类的构造与析构函数。
5. `test_placement_new`：在已有空间中构造对象。这个稍难，可以等前四个学会后再看。

在 CLion 中直接运行 `main.cpp` 所在的 `memory_management` 目标即可。不需要输入参数。

想一次只学一个例子，可以在 `main()` 中只保留对应的函数调用，暂时注释掉其他调用。

先记住这三个配对：

| 申请方式 | 释放方式 |
| --- | --- |
| `new` | `delete` |
| `new[]` | `delete[]` |
| `malloc` | `free` |

观察 `test_student` 与 `test_malloc` 的输出：前者有构造、析构信息，后者没有。这就是这两个例子要说明的区别。
