# 类和对象

## 一、类的定义

### 1、类定义格式

- class为定义类的关键字，{}中为类的主体，注意类定义结束时后面分喊不能省略。类体中内容称为类的成员：类中的变量称为类的属性或成员变量；类中的函数称为类的方法或者成员函数。
- 为了区分成员变量，一般习惯成员变量加一个特殊标识，如成员变量前面或者后面加_或者m开头，注意C++中这个并不是强制的，只是一些惯例。
- C++中struct也可以定义类，C++兼容C中struct的用法，同时struct升级成了类，struct也可以定义类，但一般情况下推荐使用class定义类。
- 定义在类里面的成员函数默认为inline.

### 2、访问限定符

- C++ 一 种 实 现 封 装 的 方 式 , 用 类 将 对 象 的 属 性 与 方 法 结 合 在 一 块 , 让 对 象 更 加 完 善 , 通 过 访 问 权 限。选择性的将其接口提供给外部的用户使用。

- public 修 饰 的 成 员 在 类 外 可 以 直 接 被 访 问 ;protected 和 private 修 饰 的 成 员 在 类 外 不 能 直 接 被 访问,protected和private是一样的。

- 访 问 权 限 作 用 域 从 该 访 问 限 定 符 出 现 的 位 置 开 始 直 到 下 一 个 访 问 限 定 符 出 现 时 为 止 , 如 果 后 面 没 有访问限定符,作用域就到}即类结束。

- class 定 义 成 员 没 有 被 访 问 限 定 符 修 饰 时 默 认 为 private,struct 默 认 为 public 。

- 一 般 成 员 变 量 都 会 被 限 制 为 private/protected, 需 要 给 别 人 使 用 的 成 员 函 数 会 放 为 public 。

  > [!IMPORTANT]
  >
  > C++ struct升级成了类
  >
  > 1、类里面可以定义函数
  >
  > 2、struct名称就可以代表类型

```C++
typedef struct ListNode
{
    ListNode* next;//不需要struct
    int data;
}LTNode;

//不需要typedef,ListNode就可以代表类型
struct ListNode
{
    void Init(int x)
    {
        next = nullptr;
        data = x;
    }
    ListNode* next;
    int data;
};
```

### 3、类域

- 类定义了⼀个新的作⽤域，类的所有成员都在类的作⽤域中，在类体外定义成员时，需要使⽤ :: 作⽤域操作符指明成员属于哪个类域。

> [!IMPORTANT]
>
> 类域解决类和类之间的命名冲突
>
> 命名空间域解决全局的函数 / 变量 / 类型的命名冲突

## 二、实例化

### 1、概念

- ⽤类类型在物理内存中创建对象的过程，称为类实例化出对象。
- 类是对象进⾏⼀种抽象描述，是⼀个模型⼀样的东西，限定了类有哪些成员变量，这些成员变量只是声明，没有分配空间，⽤类实例化出对象时，才会分配空间。
- ⼀个类可以实例化出多个对象，实例化出的对象 占⽤实际的物理空间，存储类成员变量。打个⽐⽅：类实例化出对象就像现实中使⽤建筑设计图建造出房⼦，类就像是设计图，设计图规划了有多少个房间，房间⼤⼩功能等，但是并没有实体的建筑存在，也不能住⼈，⽤设计图修建出房⼦，房⼦才能住⼈。同样类就像设计图⼀样，不能存储数据，实例化出的对象分配物理内存存储数据。

### 2、对象的大小

***只存储成员变量，不存储成员函数的地址***

> [!IMPORTANT]
>
> 内存对齐规则
>
> - 第一个成员在与结构体偏移量为0的地址处。
> - 其他成员变量要对齐到某个数字(对齐数)的整数倍的地址处。(对齐书 = 编译器默认单独一个对齐数与该成员大小的较小值)
> - 结构体总大小为：最大对齐数(所有变量类型最大者与默认对齐参数取最小)的整数倍。
> - 如果嵌套了结构体的情况，嵌套的结构体对齐到自己的最大对齐书的整数倍处，结构体的整体大小就是所有最大对齐数(含嵌套结构体的对齐数)的整数倍。

> [!CAUTION]
>
> ```c++
> class C
> {};
> C c;
> ```
>
> 没有成员变量的类对象，分配1byte是为了占位，表示对象存在

### 3、this指针

- 编译器编译后，类的成员函数默认都会在形参第一个位置，增加一个当前类类型的指针，叫做this指针。
- 类的成员函数中访问成员变量，本质都是通过this指针访问的。
- C++规定不能在实参和形参的位置显示的写this指针(编译时编译器会处理)，但是可以在函数体内显示使用this指针。

### 4、C++与C区别

***面向对象三大特性：封装、继承、多态***

| 特性 |                              C                               |                             C++                              |
| ---- | :----------------------------------------------------------: | :----------------------------------------------------------: |
| 封装 | 用结构体组织数据，用函数操作数据；通过头文件、隐藏结构体定义等方式隔离实现 | 用类把数据和操作放在一起，通过 `public`、`protected`、`private` 控制访问 |
| 继承 |  没有继承语法，通常通过结构体嵌套、组合等方式复用数据和功能  |     支持类继承，派生类可以扩展基类，并支持单继承和多继承     |
| 多态 |    没有虚函数机制，通常通过函数指针和手动维护的函数表模拟    |  支持函数重载、模板等编译期多态，以及虚函数实现的运行期多态  |

1. 封装：C++ 能直接约束对象的使用方式。

`封装不仅是把数据放在一起，还包括隐藏内部实现，只暴露必要的操作。`

```C++
class Account{
private:
	double balance = 0;

public:
	void deposit(double amount){
		if(amout > 0)
			balance += amount;
	}
	double getBalance() const{
		return balance;
	}
}
```

外部代码不能直接访问balance。C的结构体没有访问控制，但可以在头文件中只声明结构体类型，在源文件中定义内容，实现信息隐藏。

2. 继承：C++能表达类型之间的“是一种”关系

```c++
class Animal {
public:
    void eat() {}
};

class Dog : public Animal {
public:
    void bark() {}
};
```

Dog继承了Animal的能力，可以调用eat()，也可以增加自己的bark()。这里的公开继承表达了“狗是一种动物”，因此狗对象可以通过动物类型的指针或引用使用。

C可以在Dog结构体中嵌入Animal结构体来复用数据，但语言不会自动建立这种继承关系。

3. 多态：C++能让同一个接口根据对象类型执行不同操作

```c++
class Animal {
public:
    virtual void speak() { cout << "动物发声\n"; }
    virtual ~Animal() = default;
};

class Dog : public Animal {
public:
    void speak() override { cout << "汪汪\n"; }
};

Dog dog;
Animal* p = &dog;
p->speak();  // 输出“汪汪”
```

虽然 `p` 的声明类型是 `Animal*`，但虚函数会根据它指向的实际对象类型调用 `Dog::speak()`，这就是**运行期多态**。如果 `speak()` 不是虚函数，这个调用就会执行基类的版本。

C 也能用函数指针实现类似效果，但需要程序员手动组织接口和调用规则。

## 三、类的默认成员函数

默认成员函数就是用户没有显示实现，编译器会自动生成的成员函数称为默认成员函数。一个类在不写的情况下编译器会默认生成6个默认成员函数。

| 成员函数       | 典型形式                        | 作用                                   |
| -------------- | ------------------------------- | -------------------------------------- |
| 默认构造函数   | `A();`                          | 不提供参数时，初始化对象               |
| 析构函数       | `~A();`                         | 对象销毁时，执行清理                   |
| 拷贝构造函数   | `A(const A& other);`            | 用已有对象创建新对象                   |
| 拷贝赋值运算符 | `A& operator=(const A& other);` | 将已有对象的值赋给另一个已有对象       |
| 移动构造函数   | `A(A&& other);`                 | 用右值创建新对象，支持资源转移         |
| 移动赋值运算符 | `A& operator=(A&& other);`      | 将右值的内容赋给已有对象，支持资源转移 |

### 1、构造函数

构造函数是特殊的成员函数，虽然名称叫构造，但是构造函数的1主要任务并不是开空间创建对象(常使用的局部对象是栈帧创建时，空间就开好了)，而是对象实例化时初始化对象，构造函数的本质是要替代类中的Init功能，构造函数自动调用的特点就完美的替代Init。

***构造函数的特点：***

1. 函数名与类名相同。
2. 无返回值。(包括void)
3. 对象实例化时系统会自动调用对应的构造函数。
4. 构造函数可以重载。
5. 如果类中没有显示定义构造函数，则C++编译器会主动生成一个无参的默认构造函数，一旦用户显示定义编译器将不再生成。
6. 无参构造函数、全缺省构造函数、不写构造时编译器默认生成的构造函数，都叫做构造函数。但是这三个函数有且只有一个存在，不能同时存在。无参和全缺省虽然构成函数重载，但是调用时会存在歧义。
7. 编译器默认生成的构造，对内置类型成员变量的初始化没有要求，也就是说是否初始化是不确定的，看编译器。对于自定义类型成员变量，要求调用这个成员变量的默认构造函数初始化。如果这个成员变量没有默认构造函数就会报错，所以要初始化这个成员变量，需要初始化列表才能解决。

> C++把类型分成内置类型(基本类型)和自定义类型。内置类型就是语言提供的原生数据类型，如：int/char/double/指针等，自定义类型就是class/struct等关键字自己定义的类型。

### 2、析构函数

析构函数与构造函数功能相反，析构函数不是完成对对象本身的销毁，比如局部对象时存在栈帧的，函数结束栈帧销毁，它就释放了，C++规定对象在销毁时会自动调用析构函数，完成对象中资源的清洗释放工作。

***析构函数的特点：***

1. 析构函数名是在类名前加上字符~。
2. 无参数无返回值。
3. 一个类只能有一个析构函数。若未显示定义，系统会自动生成默认的析构函数。
4. 对象生命周期结束时，系统会自动调用析构函数。
5. 跟构造函数类似，不写编译器自动生成的析构函数对内置类型成员不做处理，自定义类型成员会调用它的析构函数。
6. 如果类中没有申请资源时，析构函数可以不写，直接使用编译器生成的默认析构函数，如果默认生成的析构可以用，就不需要显示写析构，但是有资源申请时，一定要写析构，否则会造成资源泄漏。
7. 一个局部域对的多个对象，C++规定后定义的先析构。

### 3、拷贝构造函数

如果一个拷贝构造函数的第一个参数是自身类类型的引用，且任何额外的参数都有默认值，则此构造函数叫做拷贝构造函数，拷贝构造函数是一个特殊的构造函数。

***拷贝构造的特点：***

1. 拷贝构造函数是构造函数的一个重载。
2. 拷贝构造函数的第一个参数必须是类类型对象的引用，使用传值方式编译器直接报错，因为语法逻辑是会引发无穷递归调用。拷贝构造函数也可以有多个参数，但是第一个参数必须是类类型对象的引用，后面的参数必须有缺省值。
3. C++规定自定义类型对象进行拷贝行为必须调用拷贝构造，所以自定义类型传值传参和传值返回都会调用拷贝构造。
4. 若未显示定义拷贝构造，编译器会自动生成拷贝构造函数。自动生成的拷贝构造对内置类型成员变量会完成值拷贝 / 浅拷贝(一个字节一个字节的拷贝)，对自定义类型成员变量会调用它的拷贝构造。

```c++
class Student {
public:
    int age;

    Student(int a) : age(a) {}

    // 拷贝构造函数
    Student(const Student& other) : age(other.age) {}
};

Student s1(18);
Student s2(s1);   // 调用拷贝构造函数
Student s3 = s1;  // 也调用拷贝构造函数
```

> [!CAUTION]
>
> 当类中含有需要***独立管理的资源(每个对象都应该引用自己的一份资源，并负责这份资源的使用和释放。)***时，通常不能直接使用浅拷贝。

```c++
class Buffer {
public:
    explicit Buffer(std::size_t n) : data_(new int[n]), size_(n) {}

    ~Buffer() {
        delete[] data_;
    }

private:
    int* data_;
    std::size_t size_;
};

//直接使用默认构造
Buffer a(10);
Buffer b = a;
```

`b.data`和`a.data`是同一个地址，会出现两个问题：

1. 修改b的数据，会影响a。
2. 两个对象析构时都会执行delete[]，造成重复释放，属于未定义行为。

***想要a、b各自拥有一份数据，就必须复制数据本身:***

```C++
Buffer(const Buffer& other)
    : data_(new int[other.size_]), size_(other.size_) {
    std::copy(other.data_, other.data_ + size_, data_);
}
```

> [!CAUTION]
>
> 指针指向原对象内部时，不能原样复制该指针

***<u>有些指针不负责释放内存，但仍不能直接浅拷贝：</u>***

```c++
struct Record {
    int values[4];
    int* selected = &values[0];
};
```

***默认拷贝`Record b = a;`后，`b.values`是新数组，但`b.selected`仍指向`a.values[0]`。这会破坏`selected`必须指向本对象内部的约束。拷贝构造函数应重新计算指针，让它指向`b.values`中对应的位置。***

>  什么时候浅拷贝可以用？
>
> 1. 谁负责释放资源？若两个副本都会释放同一资源，不能浅拷贝。
> 2. 修改副本是否影响原对象？若不影响，就要复制相应的可变数据。
> 3. 成员是否指向原对象内部？若是，拷贝时通常要重新定位。
> 4. 资源是否支持复制？若不支持，应该明确禁止拷贝或重新设计所有权。

## 四、赋值运算符重载

### 1、运算符重载

- 当运算符被用于类类型的对象时，C++语言允许通过运算符重载的形式指定新的含义。C++规定类类型对象使用运算符时，必须转换成调用对应运算符重载，若没有对应的运算符重载，则会编译报错。
- 运算符重载是具有特殊名字的函数，它的名字是由operator和后面要定义的运算符共同构成。和其他函数一样也具有返回类型和参数列表以及函数体。
- 重载运算符函数的参数个数和该运算符作用的运算对象数量一样多。一元运算符有一个参数，二元运算符有两个参数，二元运算符的左侧运算对象传给第一个参数，右侧运算对象传给第二个参数。
- 如果一个重载运算符函数是成员函数，则它的第一个运算对象默认传给隐式的this指针，因此运算符重载作为成员函数时，参数比运算对象少一个。
- 运算符重载后，其优先级和结合性与对应的内置类型运算符保持一致。
- 不能通过连接语法中没有的符号来创建新的操作符，比如operator@。
- `.* :: sizeof ?: .`注意以上5个运算符不能重载。
- 重载操作符至少有一个类类型参数，不能通过运算符重载改变内置类型对象的含义，如：`int opersator+(int x,int y)`
- 一个类需要重载哪些运算符，要看哪些运算符重载后有意义，比如Date类重载operator-就有，但是重载operator+就没有。
- 重载++运算符时，有前置++和后置++，运算符重载函数名都是operator++，无法很好的区分。C++规定，后置++重载时，增加一个int形参，跟前置++构成函数重载，方便区分。
- 重载<<和>>时，需要重载为全局函数，因为重载函数名都是operator++，this指针默认抢占了第一个形参位置，第一个形参是左侧运算对象，调用时就变成了`对象<<cout`，不符合使用习惯和可读性。重载为全局函数把ostream/istream放到第一个形参位置就可以了，第二个形参位置当类类型对象。

### 2、赋值运算符重载

赋值运算符重载是一个默认成员函数，用于完成两个已经存在的对象直接的拷贝赋值，要跟1拷贝构造区分，拷贝构造用于一个对象拷贝初始化给另一个要创建的对象。

***特点：***

1. 赋值运算符重载是一个运算符重载，规定必须重载为成员函数。赋值运算重载的参数建议写成const当前类类型引用，否则会传值传参会有拷贝。
2. 有返回值，且建议写成当前类类型引用，引用返回可以提高效率，有返回值目的是为了支持连续复制场景。
3. 没有显示实现时，编译器会自动生成一个默认赋值运算符重载，默认赋值运算符重载行为跟默认拷贝构造函数类似，对内置类型成员变量会完成值拷贝/浅拷贝，对自定义类型成员变量会调用它的赋值重载函数。
4. 如果一个类显示实现了析构并释放资源，那么它就需要显示写赋值运算符重载，否则就不需要。

## 五、取地址运算符重载

### 1、const成员函数

- 将const修饰的成员函数称为const成员函数，const修饰成员函数放到成员函数参数列表的后面。
- const实际修饰该成员函数隐含的this指针，表明在该成员函数中不能对类的任何成员进行修改。const修饰Date类的Print成员函数，Print隐含的this指针由`Date* const this`变为`const Date* const this`。

### 2、取地址运算符重载

分为普通重载和const重载，这两个函数编译器自动生成。

```c++
Date* operator&()
    {
        return this;
    	//return nullptr
    }

    const Date* operator&()const
    {
        return this;
        //return nullptr
    }
```

## 六、初始化列表

***构造函数成员初始化列表***：写在构造函数列表之后、函数体之前，用来初始化基类和成员变量。每个成员变量在初始化列表中只能出现一次，语法理解上初始化列表可以认为是每个成员变量定义初始化的地方。

```c++
#include <string>

class Student {
private:
    std::string name;
    int age;

public:
    Student(const std::string& n, int a)
        : name(n), age(a)//初始化列表
    {
        // 构造函数体
    }
};
```

与赋值相比，区别在于：***进入构造函数之前，成员的初始化已经完成。***

```c++
// 写法二：构造函数体中赋值
Student(const std::string& n, int a)
{
    name = n;
    age = a;
}
```

*对于第二种写法，`name`是一个`std::string`对象，实际过程是：**先默认构造`name`，得到一个空字符串，再进入构造函数体，最后通过赋值把`name`改成n。***

初始化列表能够明确表达“对象创建时应当处于什么状态”，所以通常优先使用。

### 1、哪些成员必须在初始化阶段设置？

#### Ⅰ、`const`成员

```c++
class Example {
private:
    const int value;
	//const int value = 10;也可以在成员声明处提供默认初始化值，这里是缺省值
public:
    Example(int v)
        : value(v)
    {
    }
};
```

`const int`必须在初始化时确定值，不能在函数体里再赋值。

#### Ⅱ、引用成员

引用构建时必须绑定对象：

```c++
class Example {
private:
    int& ref;

public:
    Example(int& x)
        : ref(x)
    {
    }
};

int number = 10;
Example e(number);
```

这里`ref`绑定到了`number`。引用不能进入函数体后再绑定。

```c++
Example(int& x)
{
    ref = x;  // 错误：ref 在此之前没有完成初始化
}
```

***<u>引用成员不会延长被引用对象的生命周期，被引用对象必须在使用时任然存在。</u>***

#### Ⅲ、没有默认构造函数的类成员

```c++
class Engine {
public:
    explicit Engine(int power) {
        // ...
    }
};

class Car {
private:
    Engine engine;

public:
    Car(int power)
        : engine(power)
    {
    }
};
```

`Engine`只有一个需要参数的构造函数，所以创建`Car`时必须告诉它如何构造`engine`。

```c++
//错误：在执行赋值语句之前，编译器就需要先构造engine，但它找不到Engine()
Car(int power)
{
    engine = Engine(power);
}
```

### 2、初始化顺序

***<u>成员按它们在类中的声明顺序初始化，而不是按初始化列表的书写顺序。最好列表顺序和声明顺序一致</u>***

```c++
class Example {
private:
    int x;  // 先声明
    int y;  // 后声明

public:
    Example()
        : y(20), x(10)//先初始化x,再初始化y
    {
    }
};
```

如何成员之间有依赖

```c++
//正确
class Example {
private:
    int x;
    int y;

public:
    Example(int value)
        : x(value), y(x + 1)
    {
    }
};

//错误
Example(int value)
    : y(value), x(y + 1)
{
}
```

虽然列表先写了`y(value)`，但x任然先初始化，计算`y + 1`时会读取尚未初始化的y。把列表换个顺序无法解决这个问题，应当调整成员声明顺序，或者直接使用构造函数参数：

```c++
Example(int value)
    : x(value + 1), y(value)
{
}
```

### 3、初始化列表也可以调用基类构造函数

```c++
#include <string>

class Person {
private:
    std::string name;

public:
    explicit Person(const std::string& n)
        : name(n)
    {
    }
};

class Student : public Person {
private:
    int grade;

public:
    Student(const std::string& n, int g)
        : Person(n), grade(g)
    {
    }
};
```

`Person(n)`是初始化`Student`对象中的基类部分，`grade(g)`是初始化派生类自己的成员。先构造Person基类部分，在初始化grade，最后执行Student构造函数体。

如果有多个直接基类，它们按继承声明中的顺序初始化，如果涉及虚基类，虚基类会更早初始化，并有派生类负责。派生类不能直接通过自己的初始化基类的数据成员，要通过基类构造函数完成。

### 4、成员声明处的默认值和初始化列表的关系

```c++
class Example {
private:
    int x = 10;
    int y = 20;

public:
    Example() = default;

    explicit Example(int value)
        : x(value)
    {
    }
};

Example a;      // x = 10，y = 20
Example b(99);  // x = 99，y = 20
```

- 初始化列表中指定了某成员，就使用列表中的初始化方式。
- 没有指定就使用该成员在声明处的默认初始化值。
- 两者都没有，才按该类型的默认初始化规则处理。

### 5、圆括号与花括号区别

```c++
//圆与花都可以使用
Example(int v)
    : value(v)
{
}

Example(int v)
    : value{v}
{
}
```

花括号初始化有一个特点：***禁止窄化转换***。

```c++
class Example {
    int value;

public:
    Example(double v)
        : value{v}  // 错误：double 到 int 属于窄化转换
    {
    }
};
```

使用`value(v)`则允许转化，但可能丢失小数部分。

对于`std::vector`，则可能有明显不同

```c++
#include <vector>

class Example {
private:
    std::vector<int> a;
    std::vector<int> b;

public:
    Example()
        : a(3, 7), b{3, 7}
    {
    }
};

a == std::vector<int>{7, 7, 7};  // 3 个元素，每个都是 7
b == std::vector<int>{3, 7};     // 2 个元素，分别是 3 和 7
```

因为花括号形式会优先考虑适用的`std::initializer_list`构造函数。这里的`std::initializer_list`和“构造函数成员初始化列表”是两个相关但不同的概率。

> [!CAUTION]
>
> 最后注意
>
> ```c++
> class Example {
> private:
>     int value;
> 
> public:
>     explicit Example(int value)
>         : value(value)//value是成员，(value)是构造函数参数
>     {
>     }
> };
> 
> class Example {
> private:
>     int x;
>     int y;
> 
> public:
>     Example(int x, int y)
>         : x(x), y(y)
>     {
>     }
> };
> ```
>
> 完全合法。初始化项左边的`value`指定成员，括号中的`value`是用来初始化它的表达式，这里同名参数会遮蔽成员，所以表达式指的是参数。

## 七、类型转换

- C++支持内置类型隐式转换为类类型对象，需要有相关内置类型为参数的构造函数。
- 构造函数前面加explicit就不再支持隐式类型转换。
- 类类型的对象之间也可以隐式转换，需要相应的构造函数支持。

```c++
class Number {
private:
    int value1;
    int value2

public:
    Number(int v)
        : value1(v)
    {
    }
    Number(int value1,int value2)
        :value1(value1)
        ,value2(value2)
    {
    }
    Number(const Number& n)
        :value1(n.value1)
        ,value2(n.value2)
        {
            
        }
};

Number a = 10;  // int → Number，调用 Number(int)
Number n = {1,2};
```

## 八、static成员

- 用static修饰的成员变量，称为静态成员变量，静态成员变量一定要在类外进行初始化。
- 静态成员变量为所有类对象所共享，不属于某个具体的对象，不存在对象中，存放在静态区。
- 用static修饰的成员函数，称为静态成员函数，静态成员函数没有this指针。
- 静态成员函数可以访问其他的静态成员，但是不能访问非静态的，因为没有this指针。
- 非静态的成员函数可以访问任意的静态成员变量和静态成员函数。
- 突破类域就可以访问静态成员，可以通过类名::静态成员来访问静态成员变量和静态成员函数。
- 静态成员也是类的成员，受public、protected、private访问限定符的限制。
- 静态成员变量不能在声明位置给缺省值初始化，因为缺省值是给构造函数初始化列表的，静态成员变量不属于某个对象，不走构造函数初始化列表。

## 九、友元

- 友元提供了一种突破类访问限定符封装的方式，友元分为：友元函数和友元类，在函数声明或者类声明的前面加friend，并且把友元声明放到一个类的里面。
- 外部友元函数可访问类的私有和保护成员，友元函数仅仅是一种声明，它不是类的成员函数。
- 友元函数可以在类定义的任何地方声明，不受访问限定符限制。
- 一个函数可以是多个类的友元函数。
- 友元类中的成员函数都可以是另一个类的友元函数，都可以访问另一个类中的私有和保护成员
- 友元类的关系是单向的，不具有交换性，比如A类是B类的友元，但是B类不是A类的友元。
- 友元类关系不能传递，如果A是B的友元，B是C的友元，但是A不是C的友元。
- 提供了便利的同时，带来了耦合度的增加，破坏了封装，所以友元不宜多用。

## 十、内部类

- 如果一个类定义在另一个类的内部，这个内部类就叫做内部类。内部类是一个独立的类，跟定义在全局相比，它只是受外部类类域限制和访问限定符限制，所以外部类定义的对象不包含内部类。
- 内部类默认是外部类的友元类。
- 内部类本质也是一种封装，当A类跟B类紧密关联，A类实现出来主要就是给B类使用，那么可以考虑把A类设计为B的内部类，如果放到private/protected位置，那么A类就是B类的专属内部类，其他地方都用不了。

```c++
#include <iostream>

class Outer {
private:
    int value;

public:
    explicit Outer(int v)
        : value(v)
    {
    }

    class Inner {
    public:
        void print(const Outer& obj) const {
            std::cout << obj.value << '\n';
        }
    };
};

int main() {
    Outer outer(100);
    Outer::Inner inner;

    inner.print(outer);  // 输出 100
}
```

虽然`value`是`Outer`的私有成员，嵌套类`Inner`的成员函数任然可以访问它。

不过，嵌套类对象不会自动关联某个外部类对象。因此访问外部类的非静态成员时，需要提供具体对象。

```c++
class Outer {
private:
    int value = 100;

public:
    class Inner {
    public:
        void print() {
            // std::cout << value;  // 错误：没有 Outer 对象
        }
    };
};
```

`Inner::print()`中的`this`是`Inner*`，不能用它找到某个`Outer`对象。前面的例子通过参数`obj`指定了要访问哪个对象。

如果外部类成员时静态的，就不需要外部类对象：
```c++
class Outer {
private:
    static int count;

public:
    class Inner {
    public:
        int getCount() const {
            return Outer::count;
        }
    };
};

int Outer::count = 10;
```

***访问权限是单向的：嵌套类可以访问外部类的私有成员，但外部类不会自动获得访问嵌套类私有成员的权限。***

```c++
class Outer {
public:
    class Inner {
    private:
        int value = 10;

    public:
        int getValue() const {
            return value;
        }
    };

    void test(const Inner& obj) {
        // int x = obj.value;  // 错误：value 是 Inner 的私有成员
        int x = obj.getValue(); // 正确
    }
};
```

如果需要让`Outer`直接访问，可以在`Inner`中声明友元：

```c++
class Outer {
public:
    class Inner {
        friend class Outer;

    private:
        int value = 10;
    };

    int read(const Inner& obj) const {
        return obj.value;  // 正确
    }
};
```

***在类里定义一个嵌套类，并不会自动创建它的对象。***

```c++
class Outer {
public:
    class Inner {
        int data;
    };
};

Outer outer
```

并不会同时创建`Inner`对象。若希望每个`Outer`对象都包含一个`Inner`，还需要声明成员变量：

```c++
class Outer {
public:
    class Inner {
    public:
        int data = 0;
    };

private:
    Inner inner;  // 每个 Outer 对象包含一个 Inner 对象
};
```

嵌套类的成员函数也可以在外部定义：
```c++
#include <iostream>

class Outer {
public:
    class Inner {
    public:
        void show() const;
    };
};

void Outer::Inner::show() const {
    std::cout << "Inner\n";
}
```

## 十一、匿名对象

- 用类型(实参)定义出来的对象叫做匿名对象，相比之前定义的类型对象名(实参)定义出来的叫有名对象。
- 匿名对象生命周期只在当前一行，一般临时定义一个对象当前用一下即可，就可以定义匿名对象。

***匿名对象经常用于传参。***

如果某个对象只需要使用一次，就可以直接创建临时对象传给函数：

```c++
void printStudent(const Student& s) {
    s.show();
}

int main() {
    printStudent(Student(20));
    //printStudent(Student{20});
}
```

因为参数是`const Student&`，这里没有为形参再复制一个`Student`对象。

***临时对象绑定到局部`const`引用时，可以延长生命周期。***

```c++
int main() {
    const Student& ref = Student(18);

    ref.show();  // 正确：临时对象仍然存在

}  // 临时对象在这里销毁
```

这里的临时对象没有在第一行的分号处销毁，而是延长到局部引用`ref`的什么周期结束。

局部右值引用1也可以产生这种效果：

```c++
Student&& ref = Student(18);
ref.show();
```

普通的非`const`左值引用则不能直接绑定这里的临时对象：

```c++
// Student& ref = Student(18);  // 错误
```

> [!CAUTION]
>
> 生命周期延长有具体规则，不能1认为只要出现引用就能一直保留临时对象。

***用临时对象初始化变量，不一定发生拷贝。***

```c++
Student s = Student(18);
```

这里=表示初始化，并不是对已有对象赋值。

在C++17及以后，对于这种同类型的初始化，s会直接构造，不会先创建一个独立临时对象，再拷贝到s。

更直接的写法是：

```c++
Student s(18);
//Student s{18};
```

## 十二、对象拷贝时的编译器优化

- 现代编译器会为了尽可能提高程序的效率，在不影响正确的情况下会尽可能减少一些传参和传返回值的过程中可以省略的拷贝。
- 如何优化C++标准并没有严格规定，各个编译器会根据情况自行处理。当前主流的相对新一点的编译器对于连续一个表达式步骤中的连续拷贝会进行合并优化，有些更新更“激进”的编译器还会进行跨行表达式的合并优化。
